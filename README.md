# hazmat

Guia de emergência para produtos perigosos (PT-BR / EN / ES), baseado no ERG 2024 e GRE 2024.
App estático: `index.html` + `fig/` (figuras extraídas do guia, fundo transparente). Sem build.

Números de classe/risco vêm de fontes externas (ADR 2023 e lista brasileira), não do ERG.
Ferramenta de apoio: confirme sempre no guia oficial e com a central de emergência.
